# Images to PDF

> Convert images to PDF in your browser. Reorder pages, adjust quality. 100% local, your files never leave your browser.

## Features

- **Privacy-first** — No backend, no uploads, no tracking. Everything happens in your browser.
- **No installation** — Works directly in the browser.
- **Accessible** — ARIA-compliant, keyboard navigation, screen reader support.

## Tech Stack

- pdf-lib
- [Vite](https://vitejs.dev/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testing

```bash
npm run test:run
```
